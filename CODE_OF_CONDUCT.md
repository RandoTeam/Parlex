# Code of Conduct

## Our standard

Be technical, specific and respectful. Critique code and decisions, not people.
Assume good faith, but support claims with logs, tests, source references or a
reproduction.

Unacceptable behavior includes harassment, discrimination, threats, doxxing,
publishing private user data, or deliberately submitting malware, hidden
tracking, or credentials.

## Scope

This applies to issues, pull requests, discussions, reviews, release comments
and project chat spaces.

## Enforcement

Maintainers may edit or remove comments, close contributions, or block accounts
for violations. For a confidential report, use the repository Security tab:
https://github.com/RandoTeam/Parlex/security/advisories

This is a small, maintainer-led project; responses are best-effort.
